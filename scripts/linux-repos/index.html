simple-capture for Linux

Version @VERSION@, for x86_64 and arm64. Updates arrive with your system's own updates.

Debian, Ubuntu and derivatives

curl -fsSL @BASE@/simple-capture.gpg | sudo tee /usr/share/keyrings/simple-capture.gpg > /dev/null
curl -fsSL @BASE@/simple-capture.sources | sudo tee /etc/apt/sources.list.d/simple-capture.sources > /dev/null
sudo apt update && sudo apt install simple-capture

Fedora, RHEL and derivatives

sudo curl -fsSLo /etc/yum.repos.d/simple-capture.repo @BASE@/simple-capture.repo
sudo dnf install simple-capture

The signing key is simple-capture.asc. Source, other packages (Flatpak, Snap, AppImage) and release notes: github.com/thtmnisamnstr/simple-capture.
